# 서울 문화행사 검색

## 1. 조건 정리

사용자 말에서 아래 세 가지를 뽑는다. 모두 선택이다. 말하지 않은 조건은 채우지 않는다.

| 조건 | 옵션 | 예 |
| --- | --- | --- |
| 키워드 (제목에 들어간 말) | `-Keyword` | 재즈, 뮤지컬, 한강 |
| 분류 | `-Category` | 콘서트, 클래식, 연극, 교육/체험, 축제-문화/예술, 축제-관광/체육 |
| 날짜 `YYYY-MM-DD` (시작일 또는 종료일) | `-Date` | 2026-11-01 |

- 「공연」「행사」「문화행사」「전시」「리스트」「목록」처럼 행사 전체를 가리키는 말은 키워드로 넣지 않는다.
  예: 「10/31일 서울 공연 리스트」 → `-Date 2026-10-31` 만 넣는다.
- 분류는 위 예처럼 API 가 쓰는 이름과 정확히 같아야 한다. 확실하지 않으면 분류 대신 키워드로 넣는다.
- 날짜는 **시작일이나 종료일이 그날인 행사만** 찾는다. 그날 진행 중이기만 한 행사(예: 10/20~11/10 연극을 10/31 로 검색)는 빠진다.
  날짜로 검색했으면 결과를 보여 줄 때 이 점을 한 줄로 알린다.
- 「이번 주말」「11월 중」처럼 기간을 말하면 기간 검색은 안 된다고 알리고, 키워드로만 찾을지 특정 날짜 하나로 찾을지 묻는다.
- 연도를 말하지 않은 날짜는 올해로 본다.

## 2. 검색

```
pwsh -NoProfile -File ${CLAUDE_PLUGIN_ROOT}/scripts/seoul-culture.ps1 -Keyword "재즈" -Category "콘서트" -Date "2026-11-01"
```

쓰지 않는 옵션은 빼고 실행한다. 사용자가 개수를 말하면 `-Count <N>` 을 붙인다 (sample 키는 최대 5건).

## 3. 보여 주기

`----KAKAO----` 줄 **위쪽**을 그대로 사용자에게 보여 준다.

## 4. 카카오톡 전송

사용자가 「카톡은 보내지 마」처럼 막지 않았으면, PlayMCP `KakaotalkChat-MemoChat` 을 **한 번** 호출한다.

- `message` 는 `----KAKAO----` 줄 **아래쪽**을 한 글자도 바꾸지 않고 그대로 넣는다 (스크립트가 200자 이내로 맞춰 둠).
- 보낸 뒤 「카카오톡 나챗방으로 보냈습니다」 한 줄을 덧붙인다.
- 결과가 0건이어도 보낸다. 오류로 검색이 실패했으면 보내지 않는다.

## 하지 말 것

- 행사 이름·날짜·장소·요금을 기억이나 추측으로 채우지 않는다. 스크립트 출력만 쓴다.
- 결과가 마음에 들지 않는다고 같은 조건으로 여러 번 호출하지 않는다. 조건을 바꿀지 사용자에게 묻는다.
- 인증키 값을 출력하거나 묻지 않는다. 키는 사용자가 환경변수 `SEOUL_API_KEY` 로 직접 등록한다.
