# seoul-culture

서울의 공연·전시·축제를 **키워드·분류·날짜로 검색**해 보여 주고,
요약을 **카카오톡 나챗방으로 보내는** Claude Code 플러그인입니다.

```
[서울 문화행사] '재즈' 134건
1. 2026 카즈미 타테이시 트리오 내한공… (12/24, 강동구)
2. 2026 카즈미 타테이시 트리오 내한공… (12/22, 영등포구)
3. [서초문화재단] 2026 서리풀 재즈페… (11/25, 서초구)
4. [서초문화재단] 2026 서리풀 재즈페… (11/11, 서초구)
외 1건
```

## 준비

- Claude Code (Windows, PowerShell 7 `pwsh` 필요)
- claude.ai 에 **PlayMCP** 커넥터 연결, 그 안의 `KakaotalkChat-MemoChat` (카카오톡 나챗방) 사용
- 데이터: [서울 열린데이터광장](https://data.seoul.go.kr) 「서울시 문화행사 정보」(`culturalEventInfo`)
  - 인증키 없이도 `sample` 키로 동작합니다. 단, **한 번에 최대 5건**만 조회됩니다.
  - 인증키를 발급받았다면 별도의 PowerShell 창에서 등록하세요. 등록 뒤에는 최대 20건까지 조회합니다.
    ```powershell
    setx SEOUL_API_KEY '발급받은키'
    ```

## 사용법

| 말하기 | 하는 일 |
| --- | --- |
| 「서울 재즈 공연 찾아줘」 | 제목에 '재즈'가 들어간 행사 검색 |
| 「서울 클래식 공연 뭐 있어」 | 분류가 '클래식'인 행사 검색 |
| 「10/31일 서울 공연 리스트」 | 2026-10-31 에 시작하거나 끝나는 행사 검색 |
| 「재즈 공연 찾아줘, 카톡은 보내지 마」 | 검색만 하고 카톡은 보내지 않음 |

스크립트만 직접 실행할 수도 있습니다.

```powershell
pwsh -NoProfile -File .\scripts\seoul-culture.ps1 -Keyword 재즈
pwsh -NoProfile -File .\scripts\seoul-culture.ps1 -Category 클래식 -Date 2026-11-01
```

## 구성

| 종류 | 이름 | 하는 일 |
| --- | --- | --- |
| skill | `seoul-culture` | 사용자 말에서 조건을 뽑아 검색하고, 결과를 보여 준 뒤 카톡 전송 |
| script | `scripts/seoul-culture.ps1` | API 호출, 결과 출력, 200자 이내 카톡 메시지 만들기 |

## 한계

- **기간 검색이 안 됩니다.** 날짜는 하나만 받고, **시작일이나 종료일이 그날인** 행사만 나옵니다.
  그날 진행 중이기만 한 행사는 빠집니다 (예: 12/18~2/9 스케이트장은 12/25 로 검색하면 안 나옴).
- 「공연」「행사」 같은 말은 검색어로 쓰지 않습니다. 제목에 그 말이 들어간 행사만 걸러져 결과가 크게 줄기 때문입니다.
- 결과는 시작일이 늦은 순서입니다. sample 키로는 그중 앞의 5건만 보입니다.
- 분류는 API 이름과 정확히 같아야 합니다 (예: 콘서트, 클래식, 연극, 교육/체험, 축제-문화/예술).
- 카톡 메시지는 200자 제한 때문에 제목을 줄이고, 넘치는 행사는 「외 N건」으로 줄여 보냅니다. 링크는 들어가지 않습니다.
